# Project Bookshelf API
Project Bookshelf API adalah aplikasi RESTful API yang dibangun menggunakan Node.js, dirancang untuk mengelola koleksi buku. API ini memungkinkan pengguna untuk menambahkan, mengedit, menghapus, dan mendapatkan informasi tentang buku dalam koleksi mereka.

## Fitur Utama

1. Menambah buku baru
2. Mengedit informasi buku
3. Menghapus buku
4. Mengambil daftar buku
5. Mencari buku berdasarkan judul
   
## Teknologi yang Digunakan

**Node.js**
   
## Cara Menjalankan

1. Clone repositori ini.
2. Instal dependensi dengan **npm install**.
3. Jalankan aplikasi dengan **npm start**.

Dengan Bookshelf API, pengguna dapat dengan mudah mengelola koleksi buku mereka secara efisien.
